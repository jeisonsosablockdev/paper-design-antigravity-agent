# Manifiesto de Diseño: Linear Tech

Marca especializada en herramientas de desarrollo de software, observabilidad y seguimiento de incidencias.

---

## 1. Principios Visuales
- **Modo Oscuro Puro**: Base en `#08090a` con superficies sutiles en `#0f1011` y elevación `#161719`.
- **Acento Eléctrico**: `#5e6ad2` utilizado exclusivamente para acciones primarias y focos activos.
- **Bordes Milimétricos**: `1px solid rgba(255, 255, 255, 0.08)`.
- **Tipografía**: `Inter` para interfaz general y `Geist Mono` para código y datos técnicos.
- **Radios**: `8px` para tarjetas, `6px` para botones e inputs.
